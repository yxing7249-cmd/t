# NEXUS TV DESKTOP V6.0

Android TV launcher project for Android 9 and later.

The complete source archive is `NEXUS_TV_DESKTOP_GITHUB_V6_READY.zip`. GitHub Actions extracts it, builds the debug APK, and uploads the APK as the `nexus-tv-desktop-v6-debug` artifact.

Minimum Android version: 6.0 (API 23). Target SDK: 28.
