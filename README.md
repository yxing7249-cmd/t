# NEXUS TV DESKTOP V6.0

Android TV launcher project targeting Android 9-compatible devices.

The source archive is extracted and built by GitHub Actions. Open the Actions tab and select the latest **Build Android APK** run. On success, download the **nexus-tv-desktop-v6-debug** artifact.

- Minimum Android: API 23
- Target SDK: 28
- Version: 6.0-skyworth

The project has not yet been physically tested on the target Skyworth television.
